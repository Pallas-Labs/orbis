Physical acceptance must measure delivery overhead before claiming it is small. |

No deploy or provisioning is claimed. Do not treat the review's estimated request rate as measured. |
| Tail-regression detection can miss a reset that advances past the old cursor before polling. Low. | No current production defect. The only production reset caller is sign-out, which cancels and releases the sender before resetting the ring. Keep that ownership rule. The standalone reset probe does not establish an epoch guarantee for future callers. |
| Missing exact upper timestamp and sibling-variant probes. Low. | Source arithmetic and strict-schema review support correctness. A loss record denotes unacknowledged history rather than proven collector loss. |
