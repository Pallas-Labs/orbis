# Playback SigNoz integration grounding

The user now requests sending playback logging to SigNoz. This supersedes the earlier clipboard-only no-upload scope. Interpret this as automatic batched delivery of the existing sanitized playback diagnostics while signed in. Keep Copy Playback Report available. No general analytics SDK, persistent device identity or unrelated application logging is requested.

At source `3a39151`, AudioPlayer on MainActor owns PlaybackDiagnostics, a 256-entry ring and fixed typed events. Its private record method captures AVPlayer state and adds one entry. Copy calls synchronous report encoding with a 256 KiB byte cap. Automatic delivery must not call that encoder inside playback callbacks. AppModel owns authentication, player and lifetime; OrbisSession shares it across app windows and CarPlay. Successful sign-in and both restored-client initializers need a sender; sign-out must detach/cancel it before stop and reset. Late callbacks must never revive an old sender or send an old batch under a new token.

The independent how pass identified the public API as Cloudflare Group plus shared createPortableApp. It authenticates the Orbis device bearer before endpoint dispatch. Vanta forwards non-audio API requests to that Group. A Bun-only endpoint would miss production. Existing request logging truncates nested annotations, so a dedicated validated export path is needed. See AudioPlayer.swift:174/199, PlaybackDiagnostics.swift:289/305, AppModel.swift:267/439/460, OrbisClient.swift:652/735, apps/api/src/group.ts, and apps/server/src/app-core.ts:2103.

Live infrastructure discovery on Vanta found existing SigNoz containers. OTLP HTTP on 127.0.0.1:4318 serves local processes; <vanta-tailnet-ip>:4318 serves the tailnet. The public HTTPS endpoint is https://otlp.parthm.me/v1/logs through the existing Cloudflare Tunnel. Cloudflare Access requires CF-Access-Client-Id and CF-Access-Client-Secret. /opt/vanta/README.md identifies private SIGNOZ_OTLP_ACCESS_CLIENT_ID and SIGNOZ_OTLP_ACCESS_CLIENT_SECRET in /opt/vanta/.app-credentials. Never read them into a model response, commit them, or embed them in the Apple app. Server-side Orbis relay can reuse device authentication and keep collector credentials in Worker secrets. No infrastructure route, restart, or deployment is performed by discovery.

SigNoz logs are queryable on Vanta in ClickHouse database signoz_logs, table distributed_logs_v2. No user log data was read during discovery. End-to-end verification should send an actual app-produced diagnostic batch through a real authenticated Orbis HTTP handler and exporter, then find its short-lived run ID in SigNoz. The Mac owns iOS builds. Use the existing fixture/native lanes and bounded local collector fixtures for retries, sign-out and slow delivery. Preserve failed artifacts before reruns and pin source hashes.

Axiom networking selects URLSession for HTTP and forbids reachability prechecks, blocking callback work and hardcoded IPs in production Apple code. Axiom concurrency requires immutable Sendable value handoff and an explicit off-main encoder; Task inherited from MainActor alone does not offload encoding. A short-lived session run UUID can correlate events, with sequence numbers, without persistent identity. Bounded retries may duplicate events after ambiguous network failures; delivery cannot be guaranteed across app exit or suspension with memory-only buffering.

Primary protocol references are https://opentelemetry.io/docs/specs/otlp/ and https://signoz.io/docs/ingestion/self-hosted/overview/. OTLP HTTP uses POST application/json to /v1/logs, decimal-string nanosecond timestamps, lowerCamelCase fields and numeric enums. Partial success is not safe to retry. Retryable OTLP response codes are 429, 502, 503 and 504, with Retry-After when supplied.

Design rubric, two points per criterion: useful searchable and correlated playback facts; no collector secret or private playback text in the client payload; bounded CPU, memory, network and retry behavior; correct session/sign-out ownership and cancellation; small interfaces fitting the existing Cloudflare/shared-handler split; repeatable native-to-SigNoz evidence without claiming physical audible-skip resolution. Require two whole-shape alternatives before implementation.
