# t3code oxlint rules

A subset of the oxlint plugin from [t3code](https://github.com/pingdotgg/t3code/tree/main/oxlint-plugin-t3code), copied from commit `2c8bdf6`. Copyright (c) 2026 T3 Tools Inc., MIT license (see `LICENSE`).

Rule IDs stay `t3code/<rule>`. `oxlint.config.ts` registers the plugin and scopes each rule. Upstream tests are not vendored.
